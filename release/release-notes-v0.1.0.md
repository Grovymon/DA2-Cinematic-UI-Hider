# DA2 Cinematic UI Hider v0.1.0

## English

First public native ASI release.

- Hold F12 for 300 ms to send one Dragon Age II `Hide main interface` toggle.
- Release does nothing; another physical hold toggles again.
- Automatic `KeyBindings.ini` detection with `V` fallback.
- F11 tracked-state emergency restore and Alt+Tab hold reset.
- Includes the x86 Ultimate ASI Loader v9.7.4 and complete English/Russian instructions.
- Passed 9 deterministic state/binding tests and an x86 ASI LoadLibrary startup smoke test.

**Requires in-game verification:** Dragon Age II was not installed on the build machine. HUD, subtitles, dialogue text/wheel and cinematic overlays have not been visually verified. This release must not be described as fully covering conversations or cutscenes until the included checklist is completed in the game.

Release ZIP SHA-256: `5026E0B3502C8FFF3C95C2CE009127EEDB6AE2BFA76F0C66D173EF229B93096B`

## Русский

Первый публичный релиз нативного ASI-мода.

- Удерживайте F12 300 мс, чтобы один раз вызвать штатную команду DA2 `Hide main interface`.
- Отпускание ничего не делает; следующее физическое удерживание переключает GUI снова.
- Автоматическое определение bind из `KeyBindings.ini`, резервная клавиша — `V`.
- F11 для аварийной попытки восстановления tracked state и сброс удерживания после Alt+Tab.
- В комплекте x86 Ultimate ASI Loader v9.7.4 и полные инструкции на русском и английском языках.
- Пройдены 9 детерминированных тестов логики/bind и тест запуска ASI через LoadLibrary в x86-процессе.

**Нужна проверка в игре:** Dragon Age II не была установлена на машине сборки. HUD, субтитры, текст/колесо диалога и cinematic overlays визуально не проверены. Нельзя считать поддержку разговоров и катсцен подтверждённой до прохождения вложенного чек-листа в игре.

SHA-256 релизного ZIP: `5026E0B3502C8FFF3C95C2CE009127EEDB6AE2BFA76F0C66D173EF229B93096B`
