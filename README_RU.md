# DA2 Cinematic UI Hider

[English instructions](README.md)

Мод переключает интерфейс Dragon Age II по удерживанию настраиваемой клавиши и предназначен для чистых скриншотов во время разговоров, катсцен и обычного геймплея.

> [!IMPORTANT]
> v0.1.0 — сборка для проверки штатного переключателя DA2. Загрузка ASI и логика удерживания собраны и покрыты автоматическими тестами, но на компьютере разработки Dragon Age II не установлена. Поэтому состав элементов, которые реально скрывает команда **Hide main interface** — особенно субтитры, текст разговора, колесо ответов и cinematic overlays — **Requires in-game verification**. Используйте [чек-лист внутриигровой проверки](docs/IN-GAME-TEST-CHECKLIST.md).

## Возможности

- Настоящий 32-битный ASI-мод, загружаемый внутрь `DragonAge2.exe`; отдельную программу запускать не нужно.
- Настраиваемая клавиша и длительность удерживания.
- Одно физическое удерживание вызывает максимум одно переключение; keyboard autorepeat не срабатывает повторно.
- Отпускание клавиши никогда не возвращает интерфейс.
- Автоматическое чтение `HideMainInterface_0` / `_1` из DA2 `KeyBindings.ini`.
- Настраиваемая резервная клавиша штатной команды DA2 (`V` по умолчанию).
- Аварийная попытка восстановления по F11 с учётом отслеживаемого состояния.
- Безопасное поведение при Alt+Tab: фаза удерживания сбрасывается, состояние GUI не меняется.
- Отладочный лог только по событиям, без записи каждого кадра.
- Нет адресов памяти игры, DirectX-хуков, игровых ресурсов и патчей исполняемого файла.

## Как это работает

В [официальном PC-руководстве Dragon Age II](https://eaassets-a.akamaihd.net/eahelp/manuals/dragon-age-ii-manuals_PC.pdf) есть команда **Hide main interface**, по умолчанию назначенная на `V`. Мод использует эту штатную команду и не придумывает несуществующий API DA2.

Ultimate ASI Loader загружает `DA2CinematicUIHider.asi` в 32-битный процесс игры. Пока окно DA2 активно, мод проверяет физическое состояние заданной клавиши. После непрерывного удерживания в течение `HoldDurationMs` отправляется ровно одно scan-code нажатие штатной команды `HideMainInterface`.

```text
GUI включён
Удерживать F12 300 мс -> один штатный toggle DA2 -> GUI выключен
Отпустить F12         -> ничего                 -> GUI остаётся выключен
Снова удерживать F12  -> один штатный toggle DA2 -> GUI включён
Отпустить F12         -> ничего                 -> GUI остаётся включён
```

Даже если держать F12 пять секунд, переключение произойдёт только один раз. Для следующего переключения клавишу обязательно нужно отпустить.

## Установка

1. Скачайте `DA2-Cinematic-UI-Hider-v0.1.0.zip` со страницы [Release v0.1.0](https://github.com/Grovymon/DA2-Cinematic-UI-Hider/releases/tag/v0.1.0).
2. Найдите папку установки Dragon Age II — в ней должна находиться папка `bin_ship`.
3. Распакуйте архив в папку Dragon Age II и согласитесь объединить `bin_ship`.
4. Проверьте итоговое расположение файлов:

   ```text
   Dragon Age II\
   └── bin_ship\
       ├── DragonAge2.exe
       ├── dinput8.dll
       ├── dinput8.ini
       ├── DA2CinematicUIHider.asi
       └── DA2CinematicUIHider.ini
   ```

5. Запустите Dragon Age II обычным способом через Steam или EA App.

Если в `bin_ship` уже есть `dinput8.dll`, вероятно, установлен другой ASI Loader. Не перезаписывайте его вслепую. Современный Ultimate ASI Loader умеет загружать несколько `.asi`: скопируйте рядом только `.asi` и `.ini` этого мода либо сначала сравните загрузчики. В релиз включён Ultimate ASI Loader v9.7.4 и его MIT-лицензия.

## Использование

Управление по умолчанию:

```text
Удерживать F12        -> скрыть GUI
Отпустить F12         -> GUI остаётся скрыт
Снова удерживать F12  -> вернуть GUI
Отпустить F12         -> GUI остаётся видим
Нажать F11            -> аварийная попытка восстановления, если tracked state = hidden
```

F12 по умолчанию используется Steam для скриншотов. Мод не блокирует эту клавишу, поэтому Steam может сделать снимок в начале удерживания. Если это мешает, установите `ToggleKey=F10` или переназначьте клавишу скриншота Steam.

## Настройка

Закройте игру и откройте `bin_ship\DA2CinematicUIHider.ini`:

```ini
[General]
ToggleKey=F12
HoldDurationMs=300
AutoDetectHideInterfaceKey=true
HideInterfaceKey=V
EmergencyRestoreKey=F11
KeyBindingsPath=Auto
OnlyWhenGameFocused=true
PollIntervalMs=10
Debug=false
```

| Параметр | Назначение |
| --- | --- |
| `ToggleKey` | Физическая клавиша для удерживания. Вместо F12 удобно использовать F10. |
| `HoldDurationMs` | Непрерывное время удерживания: от 50 до 10000 мс. |
| `AutoDetectHideInterfaceKey` | Автоматически читает фактический bind штатной команды DA2. |
| `HideInterfaceKey` | Резервная клавиша/сочетание штатной команды. По умолчанию `V`. |
| `EmergencyRestoreKey` | Однократная аварийная клавиша. По умолчанию `F11`. |
| `KeyBindingsPath` | `Auto` использует системную папку «Документы»; можно указать полный путь. |
| `OnlyWhenGameFocused` | Не даёт отправлять ввод после Alt+Tab. Оставьте `true`. |
| `PollIntervalMs` | Интервал проверки клавиатуры: от 5 до 100 мс. |
| `Debug` | Создаёт `bin_ship\DA2CinematicUIHider.log`. |

Поддерживаются буквы, цифры, `F1`–`F24`, навигационные клавиши, `PrintScreen`, основные клавиши Numpad и сочетания с `Ctrl`/`Alt`/`Shift`. Для `ToggleKey` лучше использовать клавишу без модификаторов: физически зажатый Ctrl/Alt/Shift может изменить сочетание, которое увидит DA2.

## Совместимость

- Dragon Age II для Windows PC; `DragonAge2.exe` является 32-битным процессом.
- Целевые версии — Steam и EA App.
- Мод собран как PE32 x86 и использует ту же схему Ultimate ASI Loader, что и существующие ASI-фиксы для DA1/DA2.
- Путь к bind-файлу по умолчанию: системные «Документы» → `BioWare\Dragon Age 2\Settings\KeyBindings.ini`.
- Мод не изменяет игровые файлы и сохранения.

## Известные ограничения

- **Requires in-game verification:** HUD, панели группы, субтитры, текст диалога, dialogue wheel, варианты ответа, letterbox и другие cinematic overlays визуально не проверены с v0.1.0.
- DA2 предоставляет toggle-команду, но не документированную команду `ShowUI` и не публичный API чтения фактического состояния GUI. Мод знает только о командах, которые отправил сам.
- Ручное нажатие штатной клавиши DA2, загрузка мода при уже скрытом GUI или переход игры, самостоятельно меняющий интерфейс, могут рассинхронизировать tracked state.
- Поэтому F11 не отправляет слепой toggle, когда tracked state уже «видим». Гарантировать состояние `ON`, не имея возможности его прочитать, математически невозможно.
- Мод не подавляет Steam F12.
- Если штатная команда DA2 оставляет видимыми элементы разговора или катсцены, v0.1.0 **не прошла** критерий чистого диалогового кадра. Сначала зафиксируйте оставшийся компонент, затем можно проектировать версионный Scaleform/GFx или engine hook.

## Решение проблем

- **Нет реакции и лога:** включите `Debug=true`. Если лог не появился, убедитесь, что `dinput8.dll`, `.asi` и `.ini` лежат рядом с `DragonAge2.exe` в `bin_ship`.
- **В логе ошибка конфигурации:** верните оригинальный INI из релиза и меняйте по одному параметру.
- **Отправляется не та клавиша DA2:** оставьте автоматическое определение либо назначьте `HideInterfaceKey` точно как в настройках игры.
- **Steam делает лишний снимок:** используйте `ToggleKey=F10` или переназначьте скриншот Steam.
- **После Alt+Tab удерживаемая F12 не срабатывает:** отпустите её и начните новое удерживание. Так и задумано.
- **Tracked state неправильный:** штатной клавишей DA2 сделайте реальный GUI видимым, перезапустите игру и дальше используйте только клавишу мода.
- **Установлен другой ASI-мод:** должен остаться один совместимый `dinput8.dll`; несколько `.asi` можно положить рядом. Два proxy DLL с одинаковым именем одновременно установить нельзя.

## Удаление

Удалите из `bin_ship`:

```text
DA2CinematicUIHider.asi
DA2CinematicUIHider.ini
```

Удаляйте `dinput8.dll` и `dinput8.ini` только если этот загрузчик не нужен другим ASI-модам.
